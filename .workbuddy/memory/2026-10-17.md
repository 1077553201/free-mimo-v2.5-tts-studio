# 2026-10-17

## MiMo TTS Studio（本地全功能 Demo）已建成

在 `D:/xiangmu/tts` 从零实现了 MiMo-V2.5-TTS 三模型的本地网页 Demo。

- 技术栈：FastAPI + httpx（**手写上游 SSE，不用 OpenAI SDK**）+ 原生 HTML/CSS/JS，零构建
- 三个模型：`mimo-v2.5-tts`（预置音色/风格指令/导演模式/开场标签/行内标签/唱歌/流式）、`-voicedesign`（chip 拼描述 + optimize_text_preview）、`-voiceclone`（上传/录音 + 样本库）
- 视觉：柔光玻璃双主题（`html[data-theme]` + CSS 变量），背景 4 团 blur 圆斑 + 暗幕 + feTurbulence 噪点
- 流式播放：Web Audio 按 `cursor` 排播，`createBuffer(1,n,24000)` 交给浏览器重采样，carry 处理跨块奇数字节

### 踩过的坑（重要，后续别重犯）
- `httpx.Timeout` 必须四参数齐全或给 default，只写 connect/read/write 会 ValueError
- 流式路由必须**先 `send(stream=True)` 判状态码**再包 StreamingResponse，否则 401 会被吞成断流
- `ctx.resume()` 要在点击同步栈内调用；`startDrawLoop` 里局部变量别叫 `el`（会遮蔽 <audio> 引用）
- 流式播完才能挂 `<audio>`，提前挂会让 `state()` 读到 element 的 0 进度、进度条归零
- headless Chromium 的 AudioContext 时钟比真实快 ~4.6 倍（无音频设备），调试播放时长别被误导

### 验证情况
- 用 `scripts/mock_upstream.py` + 第二实例跑通了完整链路（首包 29–43ms、12 块 PCM、历史写入、下载可用）
- 真实接口用错误 key 验证过：401 返回 `{"error":{"message":"Invalid API Key","code":"401"}}`，被正确翻译成中文提示

### 运行

Key 可在页面右上角齿轮填，或写入 `.env` 的 `MIMO_API_KEY`。

## 迭代：下拉菜单与折叠（用户反馈「插入示例配色有问题 + 页面太长」）

- **原生 `<select>` 弃用**：`<option>` 弹层由系统绘制，深色主题下白底白字看不清，且无法用 CSS 覆盖。
  改为自定义菜单（`#sampleBtn` + `#sampleMenu`，`.menu` 玻璃面板），支持点击外部/Esc 关闭。
  坑：`.menu` 用 `min-width` 时会被 `white-space:nowrap` 的子元素把宽度撑到 846px 并跑到屏幕外，
  必须改成固定 `width: 284px` + 子元素 `text-overflow: ellipsis`。
- **标签区折叠**：开场风格/行内音频标签收进 `.fold` 折叠面板，默认收起，状态存 `localStorage['mimo.folds']`。
  折叠动画用 `grid-template-rows: 0fr → 1fr`，无需 JS 测高。
- **折叠头直接显示当前值**：`(温柔 磁性)` + 「清除」按钮（`stopPropagation` 防止误触收起），
  删掉了原来单独一行 `#openingSummary`，省 40px 且不再重复。
- **设计页可选维度折叠**：`DESIGN_DIMENSIONS` 里 `required:false` 的三组收进「＋ 更多维度」按钮。
- 效果：预置页 2100px → 1622px，设计页 → 1387px。
